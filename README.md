# Food Munch 🍽️

**Food Munch** is a responsive front-end food delivery website built using HTML, CSS, and Bootstrap. It provides users with a visually appealing and mobile-friendly interface to explore various food items, learn about the service, and place orders with ease.

## 🚀 Features

- Responsive design for mobile, tablet, and desktop
- Interactive navigation bar
- Engaging hero section with call-to-action buttons
- "Why Choose Us" section showcasing key benefits
- Menu cards for various food categories (Non-Veg Starters, Veg Starters, Soups, Biryani, etc.)
- Bootstrap components for layout and styling
- FontAwesome icons integrated
